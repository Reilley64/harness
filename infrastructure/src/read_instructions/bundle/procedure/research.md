# Primary-source investigation

Resolve the question against first-party documentation, source code, specifications and owning APIs. Follow each claim back to its source. Distinguish observed facts, inference and open decisions; date mutable evidence and pin source revisions.

Write one cited Markdown report at the repository's existing research-artifact convention. Return its durable pointer, source/revision, findings, evidence limits and unanswered questions to the assigning coordinator. Report unavailable access rather than treating search/discovery as proof of a mutation. Use procedure/handoff for the return boundary.
