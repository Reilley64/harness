# Spec axis

Read the actual approved spec, ticket/comments and pinned diff. Identify missing/partial requirements, unrequested behavior and requirements apparently implemented incorrectly. Cite the requirement and file/hunk evidence for every finding.

Report a missing spec as unavailable rather than passing. Preserve the exact reviewed revision and prior findings for focused rechecks. Perform the review directly without delegation; completion prose is not acceptance, review closure or merge authority.
