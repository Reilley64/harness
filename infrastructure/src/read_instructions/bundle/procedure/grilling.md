# Grilling with documents

Map the idea as a design tree. Work in rounds: the frontier contains every decision whose prerequisites are settled. Number the frontier questions, give a recommended answer for each, and word each so "yes" accepts the recommendation. Wait for answers before the next round; dependent questions belong to later rounds.

Find environmental facts through real available tools rather than asking the human to look them up. A pending investigation is an unsettled prerequisite; continue independent questions. Use the required domain-modeling guidance as terminology and decisions crystallize.

Challenge assumptions with concrete edge cases and check statements against code. Recompute the frontier after each answer. Finish only when every branch is visited and the human confirms shared understanding. End the run for the answer; the next answer continues this same durable Griller.
