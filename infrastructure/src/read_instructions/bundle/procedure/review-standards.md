# Standards axis

Read the pinned diff/commits and all applicable repository standards/scoped guidance. Report every documented violation with source rule and file/hunk evidence, excluding mechanically enforced issues already caught by checks.

Label general design smells as judgment calls, not hard rules: mysterious names, duplication, feature envy, data clumps, primitive obsession, repeated switches, shotgun surgery, divergent change, speculative generality, message chains and middle men. Repository endorsements (including duplicated port-owned DTOs and flat explicit arguments) override generic heuristics.

Perform the review directly without delegation. For a focused recheck use the exact new revision and previous findings; state unavailable context and evidence limitations.
