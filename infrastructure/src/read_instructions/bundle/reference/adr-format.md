# ADR format

Follow the repository's ADR location and numbering convention. For file-based defaults, create docs/adr lazily and increment the highest sequential number. Use a short decision title and one to three sentences stating context, choice and why.

Add status, alternatives or consequences only when they carry useful information. The qualifying decision must be hard to reverse, surprising without context and the result of a real trade-off. Preserve dated/superseded records rather than claiming an old decision is current.
