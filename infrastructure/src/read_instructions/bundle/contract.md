# Harness execution contract

Repository root/scoped instructions and the human-approved assignment govern this work. Role procedures supplement that authority. Read the captured instruction sources; report missing required guidance instead of substituting a generic procedure.

Use the shared configured tools. Bash and MCP act with OS-user trust; a worktree isolates source, not services, ports or secrets. Tool discovery and instruction text do not grant approval for external provisioning, implementation, writes outside scope or merge. Protect credentials.

Follow backend Stop, explicit Resume, recorded effects and approval gates. Retain Unknown mutations and inspect/reconcile them before proposing retries. Handoffs, summaries and completion prose cannot settle work, reset allowances or resolve uncertainty. End a run when human input is needed; persist the question through the conversation.

Use only execution/dispatch interfaces actually supplied by Harness. Bundled role/procedure availability does not mean those paths exist. Ask for the missing capability and pause affected work. Keep model/effort continuity; native Jev Decider is a separate typed decision engine, not a conversational worker.
